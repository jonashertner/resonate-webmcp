# Support and testing

Resonate runs in the browser and keeps the free atlas in that browser. There
is no account that can recover it. Choose **download backup file** in Settings
before clearing site data, replacing a device, changing browsers, or leaving a
test address for the public site.

## install it

You can use Resonate without installing anything.

- On iPhone or iPad, open the site, use the browser's Share menu, choose **Add to Home Screen**, and turn on **Open as Web App** when it is offered.
- On Android, open the browser menu and choose **Add to home screen** or **Install app**.
- On a computer, use the install control in the address bar or browser menu when the browser offers one.

An installed copy and an ordinary browser tab use the same atlas only when
they belong to the same browser and site address.

## use it with an assistant

Resonate itself works in ordinary mobile and desktop browsers. Direct assistant
tools currently need a browser with Site tools. The simplest path is the latest
ChatGPT desktop app: enable **Settings → Browser → Permissions → Enable site
tools**, use ChatGPT Work or Codex with GPT-5.6 Sol or Terra, and open Resonate
in the built-in browser. There is no Resonate account, API key, plugin, or
separate MCP server to connect.

Site tools are not currently available in Enterprise or Edu workspaces, and
GPT-5.6 Luna does not expose them.

In Resonate, open **Settings**, then **assistant access**.

If the browser offers direct tools, press **Allow access**. These Resonate tools
can search records included in sharing and prepare a place or collection on
screen. They cannot save, delete, share, or mark visits. Close any open review
before asking the assistant to show or prepare something, then make the final
decision in Resonate yourself. Turn access off from the same place.

If direct tools are unavailable, press **Review assistant copy** instead. Read
the disclosure, download it, and hand that file to the assistant. Records
marked **Excluded from sharing** stay out of both paths. They are excluded from
links, shared files, direct messages, print, and assistant access, but included in private
backups. The assistant provider may process or retain what it reads under its
own terms.

## report a problem

Write to [resonateselect@proton.me](mailto:resonateselect@proton.me). Include:

- what you expected and what happened
- the release shown at the foot of **you**
- the device, operating system, and browser
- whether you opened a browser tab or the installed web app
- the last action that worked

Do not send your private backup file, recovery phrase, membership key, or a share
link containing places you do not mean to disclose.

Security problems can be reported privately through the addresses in
[the security policy](SECURITY.md).
